# ExperimentLab

### Платформа для планирования и анализа A/B-тестов

ExperimentLab помогает планировать эксперименты, сравнивать контрольную и тестовую группы и анализировать результаты, чтобы принимать продуктовые решения на основе данных.

## О проекте

ExperimentLab — учебный продуктовый проект, посвящённый планированию и анализу A/B-экспериментов.

Продукт объединяет управление экспериментами, работу с метриками и визуальное представление результатов в одном интерфейсе.

**Цель проекта** — сделать процесс работы с продуктовыми гипотезами более понятным и системным: от постановки эксперимента до анализа полученных данных.


---

## Проблема

При работе с A/B-тестами важно не только запустить эксперимент, но и системно управлять им: фиксировать гипотезы, отслеживать статус, собирать данные и сравнивать результаты.

Когда информация разрознена, сложнее контролировать ход экспериментов и понимать, какие выводы действительно можно сделать на основе данных.

## Решение

ExperimentLab объединяет управление экспериментами и анализ результатов в одном рабочем пространстве.

Основной акцент сделан на понятном процессе работы: пользователь создаёт эксперимент, определяет метрики, добавляет данные и сравнивает контрольную и тестовую группы.

---

## Возможности продукта

- **Управление экспериментами** — создание экспериментов, описание гипотез и отслеживание статусов.
- **Сравнение вариантов** — анализ конверсии контрольной и тестовой групп.
- **Визуализация данных** — графики и сводные показатели для удобного изучения результатов.
- **Импорт и экспорт** — загрузка данных из CSV и сохранение результатов для дальнейшей работы.
- **Локальное хранение** — данные сохраняются в браузере без обязательного подключения к серверу.

## Продуктовый подход

### Целевая аудитория

ExperimentLab ориентирован на специалистов, которым нужно планировать эксперименты и анализировать результаты без сложной инфраструктуры.

- **Продакт-менеджеры** — формулируют гипотезы и оценивают влияние изменений на продуктовые метрики.
- **Аналитики** — сравнивают показатели контрольной и тестовой групп.
- **Небольшие продуктовые команды** — систематизируют эксперименты и хранят результаты в одном месте.

### Основная продуктовая гипотеза

Если предоставить пользователю единое пространство для управления A/B-экспериментами и сравнения результатов, ему будет проще организовывать эксперименты и принимать решения на основе данных.

Эту гипотезу необходимо проверять на реальных пользователях: оценивать удобство сценариев, частоту использования и успешность выполнения ключевых задач.

### Ключевые продуктовые решения

| Решение | Обоснование |
|---|---|
| Единый список экспериментов | Помогает отслеживать все тесты и их статусы |
| Сравнение контрольной и тестовой групп | Позволяет видеть различия в ключевых метриках |
| Визуализация результатов | Упрощает восприятие данных и сравнение вариантов |
| Импорт и экспорт данных | Позволяет работать с данными из внешних источников |
| Локальное хранение | Упрощает запуск продукта без регистрации и настройки сервера |

## Метрики успеха

Для оценки полезности ExperimentLab можно использовать следующие метрики.

| Метрика | Что показывает |
|---|---|
| Activation Rate | Доля пользователей, создавших первый эксперимент |
| Experiment Completion Rate | Доля начатых экспериментов, для которых внесены результаты и завершён анализ |
| Time to First Insight | Время от создания эксперимента до получения первого полезного вывода |
| Task Success Rate | Доля пользователей, успешно выполнивших ключевой сценарий |
| Retention Rate | Доля пользователей, вернувшихся к продукту через выбранный период |

На текущем этапе это предлагаемые метрики для будущей проверки, а не измеренные результаты. Для их расчёта потребуется собирать данные об использовании продукта и проводить пользовательское тестирование.

## Ограничения проекта

ExperimentLab работает как клиентское приложение без собственного сервера и базы данных.

- Данные сохраняются локально в браузере пользователя.
- Данные не синхронизируются между устройствами и браузерами.
- При очистке данных браузера сохранённые эксперименты могут быть потеряны.
- Достоверность статистических выводов зависит от корректности расчётов и исходных данных.
